The 95th percentile is the value that 19 of 20 requests beat

Definition, formula and a worked example

Definition

For n sorted latencies x_1 \le x_2 \le \dots \le x_n, the percentile p is read at rank

\accent{r} = \left\lceil \frac{p}{100}\, n \right\rceil, \qquad \text{p95} = x_{\accent{r}}

Worked example

With n = 200 requests and p = 95:

r = \left\lceil \tfrac{95}{100} \cdot 200 \right\rceil = 190

So p95 is the 190th smallest latency. The slowest 10 requests are above it.

Symbols

n
number of requests in the window
p
percentile, from 0 to 100
r
rank of the value to read (1 is the smallest)
