# D3 (`libs: d3`)

`d3` is a global (v7). `Visuals.d3` is ready to use after the page boots. Use D3 only for charts Chart.js cannot do: heatmaps, treemaps, networks, histograms and box plots, small multiples, custom scales, annotated timelines.

## Helpers (`const v = Visuals.d3;`)
- `v.series(domain)`: ordinal colour scale; the seventh and later names map to the neutral "other". Cap at six names anyway.
- `v.sequential(min, max)`: colour scale for ordered magnitude (low to high). Use for heatmaps.
- `v.diverging(min, mid, max)`: for values around a meaningful midpoint (change vs baseline). The middle is neutral; print numbers in cells.
- `v.steps(min, max)`: five discrete bands from the sequential ramp (choropleth-style).
- `v.axis(g)`: call on an axis group so the stylesheet styles it: `g.call(d3.axisBottom(x)).call(v.axis)`.
- `g.call(v.grid(d3.axisLeft(y), innerWidth))`: light grid lines.
- `v.tooltip(container)`: returns `{show(html, event), hide()}`. **`show` takes HTML, so pass every data value through `Visuals.esc()`**: `tip.show("<span class='k'>" + Visuals.esc(d.name) + "</span><span class='v'>" + Visuals.fmt.num(d.v) + "</span>", event)`.
- `v.fmt`: same as `Visuals.fmt`.

## SVG skeleton
```html
<figure>
<div id="chart" class="chart"></div>
<figcaption>Source: ...</figcaption>
</figure>
<script>
const data = JSON.parse(document.getElementById("data").textContent);
const host = document.getElementById("chart");
function draw() {
  host.textContent = "";
  const w = host.clientWidth, h = host.clientHeight, m = { top: 8, right: 12, bottom: 28, left: 40 };
  const svg = d3.select(host).append("svg").attr("viewBox", [0, 0, w, h]).attr("role", "img")
    .attr("aria-label", "Finding in a sentence.");
  // scales, axes, marks...
}
draw(); new ResizeObserver(draw).observe(host);
</script>
```
Redraw on resize so labels stay legible. Redraw on theme change when you use computed colours: `Visuals.onTheme(draw)`. If you only use CSS classes or `var(--token)` for colour, nothing else is needed.

## Colour in SVG
Prefer classes: `.series-line`, `.series-area`, `.series-bar`, `.series-point`, `.slice`, `.cell`, `.fill-1`..`.fill-6`, `.stroke-1`.., `.svg-text`, `.svg-muted`, `.svg-axis`, `.svg-grid`, `.svg-node`, `.svg-edge`, `.svg-arrow`, `.chart-label`, `.chart-value`, `.chart-ref` (reference line), `.chart-annotation`, `.ring-track` and `.ring-value` (progress ring), `.spark` (sparkline). For scale-driven fills, use the helper scales; they return real colours from the current theme, and the lint allows `.attr("fill", d => scale(d))`.

Text on heatmap cells: `Visuals.readable(cellColour)` returns a text colour that passes 4.5:1. **Set it with `.style("fill", ...)`, not `.attr("fill", ...)`**: classes such as `.chart-value` set `fill` in CSS, and CSS beats an SVG attribute, so the attribute is silently ignored (the number then vanishes on the darkest or lightest cells). The same applies to any computed colour on an element that also has a class that sets `fill` or `stroke`.

## Rules
- Do not use `.html()`, `.innerHTML`; use `.text()`.
- Do not use `d3.json`, `d3.csv`, `d3.text`, `d3.xhr` (they fetch). Data comes from the `#data` block: `d3.csvParse(string)` is fine for an embedded CSV string.
- Do not use `d3.select("body")`; select inside your fragment.
- Rounded numbers in labels via `Visuals.fmt`.
- Treemap and network layouts: limit to about 60 nodes; label only the largest; show the rest on hover.
- Histogram: `d3.bin()` with explicit thresholds, bars touching (padding 1px), x axis titled with the unit.
- Axes on top (`d3.axisTop`) need `margin.top` of about 24 px, or the labels clip. Bottom axes need about 28; left axes about 40 plus the longest label.
- Heatmap: sequential for magnitude, diverging for change. Always include a legend using `.ramp` (`<div class="ramp"><i class="seq-1"></i>...<i class="seq-5"></i></div>` with low and high labels) and the numbers in cells when cells are large enough.
